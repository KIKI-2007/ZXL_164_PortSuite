# ZXL Controlling 1.6.4

Client-side key binding browser for Minecraft 1.6.4 Forge.

- Open the browser with the configurable **P** key (Options → Controls → ZXL Controlling).
- Search key descriptions as you type.
- Filter all bindings, conflicting bindings, or unbound bindings.
- Page through long binding lists.
- Read-only by design: edit or reassign keys in the vanilla Controls screen.

The current implementation is an early integration and still requires a full in-game compatibility pass with the target modpack. See the root README and `docs/BUILD_AND_TEST.md`.
