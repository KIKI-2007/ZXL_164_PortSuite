# ZXL 1.6.4 Port Suite

Source scaffold for five independent Minecraft 1.6.4 Forge modules: Controlling164, Apple164, RecipeViewer164, Backup164, and Tooltip164.

**Status:** Alpha engineering scaffold. The repository includes core utilities and a CI build pipeline, but the in-game GUI/HUD/recipe/backup/tooltip integrations are not complete. Published Alpha JARs are development artifacts, not finished feature ports.

The canonical project and build files are in [ZXL_164_PortSuite/](ZXL_164_PortSuite/). See its README and `docs/BUILD_AND_TEST.md` for build instructions and validation status.
