# ZXL 1.6.4 Port Suite

Source scaffold for five independent Minecraft 1.6.4 Forge compatibility ports: Controlling164, Apple164, RecipeViewer164, Backup164, and Tooltip164.

**Status:** Alpha scaffold. Core utilities have local Java smoke checks, but Forge integration and in-game features are not yet complete. No release JARs are provided by this commit.

See `ROADMAP.md` and `docs/BUILD_AND_TEST.md` for scope and validation status.
